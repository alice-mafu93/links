## Week 1 - History
- Cave paintings and tally marks is how writing began 
- Typewriters were the start of standarized text and influenced modern computers keyboards
## Week 2 - Bits and Bytes
- RAM is volatile while SSD and HDD store data permanently 
- ASCII assigns numeric codes to characters
## Week 3 - Structure of Text
- Markdown and HTML help format and organize text
- Special characters are #,$,&,*,@
## Week 4 - Manipulating Text and Text Editors
- VS Code and Pycharm are used by developers
- Touch typing improves typing speed and reduces mistakes
## Week 5 - Command Line Interfaces
- ld, cd and pwd commands help with moving files and navigating
- Secure remote access is done by SSH
